## Быстрый старт (минимум для продакшена)

```bash
# 1. На сервере
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2

# 2. Деплой
git clone <repo> /opt/news-aggregator
cd /opt/news-aggregator
cp .env.example .env
nano .env  # заполнить секреты
npm install

# 3. Запуск
pm2 start ecosystem.config.js
pm2 startup
pm2 save

# 4. Проверка
pm2 logs
pm2 status
```
